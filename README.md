# 📊 [Industrial Automation] Procurement Analytical Dashboard

## Project Overview
This project delivers a procurement analytics solution based on the business operations of **Ener Tech Solutions Sdn Bhd** for the **metal industry sector.** It demonstrates how I bridge the gap between operational data modeling in **Excel** and executive-level interactive visualization in **Power BI** to showcase **professional analytical capabilities** and **industry domain knowledge.**

## 🛠️ Tech Stack & Tools
* **Data Transformation & Modeling**: Excel (Pivot Tables, Data Validation)
* **Business Intelligence**: Power BI (DAX Measures, Data Modeling, Cross-filtering)
* **Key Metrics Tracked**: 
  * **OTIF Rate (On-Time-In-Full)**: Measured via custom DAX division logic.
  * **Stockout Alerts**: Dynamic `DISTINCTCOUNT` filtering for SKU reorder point (ROP) safety breaches.
  * **Supplier Performance Matrix**: Multi-variable bubble chart (Spend vs. OTIF Rate vs. Delay Count).
